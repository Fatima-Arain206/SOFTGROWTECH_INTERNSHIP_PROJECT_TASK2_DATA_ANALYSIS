# Customer Retention Analysis

## 📌 Overview
This project analyzes customer churn data to identify returning vs. churned customers and understand the behavior patterns behind retention. It was completed as **Task 2** of the Data Analysis Internship at **SoftGrowTech**.

## 🎯 Objective
- Identify returning (retained) vs. churned customers
- Analyze behavior patterns linked to retention
- Visualize retention trends
- Generate actionable insights to reduce churn

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## 📂 Dataset
Dataset sourced from [Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) — Telco Customer Churn dataset.

## 🔍 Steps Performed
1. Loaded the dataset using Pandas
2. Cleaned data (handled missing values, fixed data types)
3. Identified churned vs. retained customers
4. Analyzed behavior patterns (contract type, tenure, charges, services used)
5. Created visualizations (bar charts, churn rate by category) to present findings
6. Explained key drivers behind customer churn/retention
