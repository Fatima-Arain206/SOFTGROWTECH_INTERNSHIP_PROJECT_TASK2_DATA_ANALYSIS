# A/B Testing Analysis

## 📌 Overview
This project analyzes two datasets (Control vs. Test group) to compare performance and determine which approach performs better. It was completed as **Task 2** of the Data Analysis Internship at **SoftGrowTech**.

## 🎯 Objective
- Load and clean both datasets (Control & Test groups)
- Compare key performance metrics between the two groups
- Visualize the differences
- Draw data-driven conclusions on which version performs better

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## 📂 Dataset
Dataset sourced from [Kaggle](https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing) — Marketing A/B Testing dataset.

## 🔍 Steps Performed
1. Loaded both Control and Test group datasets using Pandas
2. Cleaned data (handled missing values, fixed data types)
3. Compared key metrics (e.g., conversions, clicks, spend) between groups
4. Performed statistical comparison to check significance of differences
5. Created visualizations (bar charts, comparison plots) to present results
6. Drew conclusions on which approach (Control or Test) performed better
