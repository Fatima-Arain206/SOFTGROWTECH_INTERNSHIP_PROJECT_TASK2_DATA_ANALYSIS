# Data Storytelling Project

## 📌 Overview
This project uses the Netflix Movies & TV Shows dataset to build a data-driven narrative — going beyond charts to tell a clear, engaging story about content trends over time. It was completed as **Task 2** of the Data Analysis Internship at **SoftGrowTech**.

## 🎯 Objective
- Choose and explore a dataset with a compelling narrative angle
- Analyze key trends and patterns
- Build visualizations that support a clear story
- Present findings in a narrative, easy-to-follow format

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## 📂 Dataset
Dataset sourced from [Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows) — Netflix Movies and TV Shows dataset.

## 🔍 Steps Performed
1. Loaded and explored the dataset using Pandas
2. Cleaned data (handled missing values, fixed data types)
3. Identified key trends (content growth over years, genre popularity, country-wise distribution)
4. Built visualizations to support each part of the story
5. Structured findings into a narrative — beginning (context), middle (trends/patterns), end (conclusion)
